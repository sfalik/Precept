## What was built

New (all in the working tree, uncommitted):
- `/home/sfalik/source/repos/Precept/tools/Precept.MatrixTools/CellTestConverter.cs` — `convert-cells` converter. Per defined cell with a base witness it emits: a base row (must reject naming the cell's obligation), one row per discharge addition (must accept via the expected strategy), one row per near-miss (must still reject, same obligation). Each row keeps two expectations apart: `expected` (what the definition requires) and `head` (`mustPass` / `expectedFailure` where the cell records the strategy unbuilt / `unstated` where the cell records no built status — never invented). The obligation a row must name is identified mechanically: the cell's stored canonical WP key is recomputed from the base program through `WpCalculator`, and the matching enumerated obligation supplies a structural key (field, bound kind, bound, context class). Anything unconvertible yields a named skip record with the specific reason — no generic "not supported" anywhere.
- `/home/sfalik/source/repos/Precept/tools/Precept.MatrixTools/ManifestRunner.cs` — `run-manifest` executor. Verdicts each row from structured compile results: proof-ledger `ProofObligation` records (requirement subtype `IntervalContainmentProofRequirement`/`NumericProofRequirement` matched by field + bound + context class, disposition, strategy) and diagnostic codes/stages — never message text.
- Tests: `/home/sfalik/source/repos/Precept/test/Precept.MatrixTools.Tests/CellTestConverterTests.cs` (13 tests) and `ManifestRunnerTests.cs` (8 tests) — written before the implementation.
