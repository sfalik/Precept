# Compiler Readiness Plan — 2026-06-11 (Revised: Compiler-Only)

> **A fresh plan, finishing the COMPILER.** Goal: take the Precept compiler to **100% of the canonical language spec** — all datatypes, all grammar, all constructs, all diagnostics — on top of a **sound, right-sized fault floor**, AND capture in canonical design every runtime decision the compiler work forces, so the eventual runtime build has a complete spec. The floor is made position-total and trimmed of over-reach; the language is widened against a floor that holds; runtime CODING is deferred to a separate initiative with its design captured here.

## The boundary (non-negotiable)

This plan finishes the compiler. It does **not** build the runtime. The dividing line is structural, not a matter of phase numbering:

**IN SCOPE**
- **All COMPILER code work** — proof engine, type checker, binder, graph analyzer, parser, lexer, pipeline tail, diagnostic emission, the Roslyn build-time analyzers, the conformance program's compiler-side edges. Verifiable today via `precept_compile` / `dotnet build` / `dotnet test` with the runtime stubbed.
- **ALL canonical DESIGN/doc work** — both compiler canon (`docs/compiler/*`, `docs/language/*`) AND **runtime canonical design** (`docs/runtime/*.md`: `evaluator.md`, `fault-system.md`, `result-types.md`, `descriptor-types.md`, `runtime-api.md`). Wherever a compiler decision needs a runtime behavior captured so nothing is lost, that capture is **in scope here** even though the coding that honors it is deferred.

**OUT OF SCOPE — the separate runtime initiative**
- Runtime **CODING**: the evaluator / governance-constraint sweep / ingress enforcement / `Fire` / `Update` / `InspectFire` / `InspectUpdate` / `Restore` / the executable model.
- **Verified ground truth:** `src/Precept/Runtime/Evaluator.cs` — `Fire`/`Update`/`InspectFire`/`InspectUpdate`/`Restore` are all `throw new NotImplementedException()`, each tagged *"once the executable model is designed"*. There is **no** constraint/governance sweep, **no** runtime enforcement, and the executable model is not even designed. Any plan item whose correctness/soundness/exit-criterion **requires the runtime to execute** is runtime-code → deferred (its design captured), not compiler work.

**The discipline this boundary imposes:**
1. Every retained item must be **compiler-completable** — provable green via `precept_compile`/`dotnet build`/`dotnet test`, with no exit criterion that asserts a runtime-execution outcome (no "governance refuses the write", no "`Fire` returns X", no "the magnitude cancels to 12.00").
2. Every deferred item must carry a **runtime-canon capture obligation** — the specific `docs/runtime/*.md` section that must hold its design so the deferred coding has an acceptance spec.
3. The **matched-pair** rule: a compiler change that *admits* an operation the stubbed runtime cannot perform is a false-accept and must **not** ship ahead of its runtime-canon capture (prevention-engine posture: unprovable/unperformable ⇒ reject, not admit).

## Context

Three strategic decisions and three owner decisions reset the plan.

**Strategic (carried forward):** (1) The **compile-time niche decision** established that the fault floor is **prove-or-reject** (total, stable) and everything beyond it is **flag-sound, revisited after the runtime**. (2) The **fault-floor research** found the engine both **over-stepped** the floor (the band-containment lane — OutOfRange/LengthBound/CountBound + the PRE0078 declared-band check — is rule-preservation misclassified as faults) and **under-built** it (10 obligation-position fail-open holes; several false-"Proved" sites). (3) The **runtime is a pure stub**, which is what makes this a compiler-only plan with a captured runtime handoff.

**Owner decisions applied this revision (do not re-litigate):**
- **OVERFLOW PARKED.** Decimal-representability overflow (and its temporal-arithmetic twin — same representability genus) is an accepted, documented, **temporary known fault**. Do **not** build the representability-overflow obligation/family; no bounds-checking, no multi-field magnitude proof; the number-model redesign is parked (GATE-A resolves as **park**). Document overflow as a known limitation; **never claim it prevented.**
- **BAND RIGHT-SIZING SPLITS.** The COMPILER parts of the band scale-back (reclassify from fault/prove-or-reject to a compile-time flag/warning; trim the registry; amend the spec) are **in scope and compiler-pure** — they only stop the compiler falsely rejecting valid precepts. The runtime governance **enforcement** (the sweep that actually enforces reclassified bounds, and the discharging constraints that make committed-state tier-2 discharge sound) is **runtime-code → deferred**, with its design captured.
- **ATOMICITY RELAXED.** Pre-release, no users, stubbed runtime ⇒ transient gaps are harmless. **Drop** the "atomic coordinated move so bounds are never enforced nowhere" machinery (it protects a running product we do not have). **Keep** only internal-correctness orderings — specifically, the fault registry must be honest **before** the Phase-2 position-totality checker reads it. Prefer simple incremental sequencing over all-or-nothing merges.

Inputs (de-duplicated into a single register; see § Coverage ledger and § Provenance): 16 floor gaps, 8 scale-backs, 10 registry corrections, **236 spec-coverage gaps** (619-row audit), and **43 mined obligations** recovered from the triage of **32 prior docs (28 superseded + 4 archived)** so nothing is lost.

## Decisions captured

- **The fault floor is a 10-family, position-total, prove-or-reject core** PLUS the static edge owed by binder/type-checker totality. The ten families: divisor≠0; sqrt/threshold≥0; presence; collection-nonempty-on-access; collection-nonempty-on-mutation; index-in-bounds; key-presence; operation-site qualifier+dimensional compatibility (incl. correct UCUM factors); temporal-presence/access; computed-arg function computability. **Decimal-representability overflow is NOT a floor family** — it is a parked, documented known fault (see § Overflow parked). The static traps (TypeMismatch/UndeclaredField/InvalidMemberAccess/FunctionArityMismatch) stay as defense-in-depth, no proof obligation owed.
  > *Was "11-obligation-family" — corrected to 10 by the overflow-park decision. The representability family (decimal + temporal) leaves the prove-or-reject floor and becomes a documented known limitation.*
- **Three soundness disciplines are minimum discharge power, not optional:** sequential staleness (`ReassignedBefore`/`CountInvalidatedBefore`), **same-transaction** write-aware tier-2 discharge, and intra-guard short-circuit conjunct narrowing for presence. (The **committed-state / cross-event** half of write-aware discharge is sound only when the runtime sweep enforces the discharging constraints — that soundness premise is captured in runtime canon and deferred; the compiler stays sound-by-refusal in the interim.)
- **Overflow parked.** Decimal-representability overflow and temporal-arithmetic overflow are accepted, documented, **temporary known faults**. No representability obligation is built; `NumericOverflow` (and, if ever added, `TemporalOverflow`) remain defense-in-depth fault codes whose `[StaticallyPreventable]` partner is an honestly-disclosed **gap**, not a guarantee. Canon must never claim overflow prevented. **`philosophy.md` reconciliation is OWNER-GATED** — surfaced, never auto-edited.
- **Band right-sizing splits.** The band-containment lane (OutOfRange/Length/Count + PRE0078-band) exits the prove-or-reject floor **for non-proof-carrying fields**: the compiler downgrades to a flag-sound proven-violation warning, trims the registry, and amends the spec (all in scope). The runtime **governance enforcement** of the reclassified bounds is deferred to the runtime initiative with its design captured. **Frank A6 framing:** prevention is **relocated** (compile → runtime governance), not weakened; `philosophy.md` L53's enumerated compile-time impossibilities (divisor, empty-collection) are all RETAINED floor families. Bands are not in that list. *(Overflow is the one genuine weakening — a disclosed parked gap, distinct from the band relocation. Do not blur the two.)*
- **The carries-proof boundary** (not band-vs-not) is the real line: mincount's count>0 discharge and sign-modifier/rule-fact preservation do NOT exit. *(With overflow parked, "bounds consumed by representability proofs" no longer pulls any bounds proof-carrying — the non-proof-carrying band exit is cleaner.)*
- **Atomicity relaxed.** The "one coordinated atomic move so bounds are never enforced nowhere" machinery is **dropped** (it protects a running product we do not have). The only retained ordering is internal correctness: the registry must be honest before the Phase-2 position-totality checker reads it. Compiler band reclass, registry trim, and spec amendments land incrementally.
- **Position-totality is a floor property AND a hard runtime precondition.** The per-keystroke `InspectFire` path runs guards with no fault lane in `Prospect` (Certain/Possible/Impossible), so a fail-open obligation position would crash the eventual inspector. Durability is structural via the catalog `ChildExpressionPositions` projection + a 3-layer creation-exhaustiveness checker. *(The checker is compiler work, verifiable today; the InspectFire precondition is captured in `evaluator.md §10` so the deferred runtime build inherits it.)*
- **Three categories, not two:** fault floor (prove-or-reject) / definition incoherence (PRE0079-on-default, PRE0164, PRE0115 — always-Error, every Create fails, neither fault nor flag) / flag layer (post-runtime, warning-default with earned per-diagnostic error promotion).
- **Registry repartition lands whole in one pass** (so the Phase-2 checker reads honest codes — the one retained ordering): REMOVE OutOfRange/Length/Count FaultCodes; **`NumericOverflow` stays as a documented known-limitation code, NOT retargeted to a built obligation** (overflow parked); ADD IndexOutOfBounds (route PRE0100) / KeyNotFound (route PRE0099) + the UnexpectedNull bijective row (route PRE0116); PRE0101→DuplicateKey only under require-absence (GATE-D); RETIRE the generic `_ => DivisionByZero` backstop for per-family honest routing; add ProofStrategy.Vacuous. **`FaultCode.TemporalOverflow` is NOT added** (temporal overflow parks with decimal overflow).
- **The flag-sound universal niche layer is explicitly POST-RUNTIME and out of scope** (it needs the shipped runtime as its error-promotion oracle).
- **The definition-evolution deploy lane is its own separate decision — confirmed OUT** of floor scope.
- **Provenance (Frank B3):** the obligation register is **43 mined obligations recovered from the triage of 32 prior docs (28 superseded + 4 archived)**; the 4 archived docs' transferred obligations are present in the 43-register. *(Replaces the prior "28 superseded" / "all 32" inconsistency.)*
- **Standing declines recorded:** convex polyhedra and predicate abstraction are permanently off the interactive path (data-dependent latency breaks determinism R2; theorem-prover step breaks R1); solver-free scope lock per spec §0.6 #3.
- **Forwarding-fact vacuous suppression is verified SOUND** (GraphAnalyzer.BuildEdges ignores row.Guard, so reachability over-approximates and unreachable=structural) — ProofStrategy.Vacuous records it honestly.
