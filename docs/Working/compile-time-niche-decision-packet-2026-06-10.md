# Compile-Time Niche — Decision Packet

> Evidence packet for the pivotal decision: Option 1 (fault floor + governance + live inspector) vs Option 2 (all-in compile-time checking as Precept's niche). Verdict: **partial** — a three-layer shape under a flag-soundness contract. The decision is the owner's; this packet informs it.

## Verdict

**Clear case for Option 2:** partial · **Confidence:** medium

### The teachable line

> If your precept compiles, no operation can ever fault; anything the compiler flags is proven wrong for every possible entity — a rule that can never apply, a prohibition that can never fire, a step that can never succeed, a state work can never leave; and everything your actual data decides is enforced on every operation, with a stated reason.

## The niche (what compile-time uniquely wins)

### [defect-class] Silent wrong-success routing: dead reject rows and shadowed transition rows under first-match ordering

- **Why compile-time wins:** The failure signature is a clean governed SUCCESS (embargoed shipment dispatches; premium case books as standard), so governance never refuses and the inspector shows a plausible-looking outcome — an authored prohibition that silently never fires is unobservable by any outcome-watching surface. Tier-1 (unconditional row before guarded/reject rows) is purely syntactic; probe-verified to compile with zero diagnostics today.
- **Severity/value:** High-to-critical: silent disablement of declared policy; the dead-reject variant is a governance-integrity breach (the author DID write the control; the file lies to its reader and to auditors).
- **Engine power needed:** Tier 1: none beyond syntax (row-order scan per state×event). Tier 2: pairwise guard implication over the existing interval/choice representations; conservative outside the fragment.
- **Language change needed:** None.
- **Expressiveness cost:** None — flags only proven-unreachable rows; the specific-first/fallback-after idiom is untouched.

### [defect-class] Definition self-contradiction family: contradictory rule sets (per guard scope and per state), vacuous/dead rules and guards, hook-vs-ensure and row-composition unsatisfiability, dead access-mode guards, quantified-form extensions of all of these

- **Why compile-time wins:** These are absences — a rule that never governs, a guard that never engages, a transition that refuses for ALL inputs. Per-scenario simulation cannot render an absence in principle (every scenario simply passes, or refuses with text that blames the data for a definition bug). Probe-verified holes everywhere the existing folds stop: hook-vs-ensure (ProbeM), row composition, arg-environment contradictions, quantified twins of PRE0154 silent while the scalar twin warns. Shipped corpus samples contain live instances (library-book-checkout exit-clear vs Lost ensure).
- **Severity/value:** High-to-critical: unenterable states and never-committable rows strand processes at graph-clean states; vacuous rules are audit-grade dead controls; spec §0.6 items 7–10/12 already commit to most of this and are specification-only — this is finishing the language's own declared design.
- **Engine power needed:** Existing interval/satisfiability/presence folds pointed at new positions (arg environments, hook chains, target-state ensures, access-mode guards, quantifier bodies via element bounds), plus per-state constraint-set intersection. The locked relational/octagon design supplies the cross-field leg. MANDATORY PREREQUISITE: make the analysis guard-SCOPE-sensitive — verified live this session that PRE0155 currently fires a false 'no valid configuration' claim across disjoint guards (premium-cap vs silver-floor), so the shipped increment over-claims today.
- **Language change needed:** None.
- **Expressiveness cost:** None when shipped as proven-violations-only flags; the false-positive fix is what keeps it none.

### [defect-class] Clock-decay classification: now() in unconditional rules (entity bricked by time alone, including the remedial operation), closing-window guards (expiring-exit traps), clock-gated editability windows

- **Why compile-time wins:** The cleanest structural counterexample to the inspection paradigm: the designed inspector evaluates at real wall-clock with no time-travel control anywhere in the manifest or prototype — the author literally cannot ask 'what happens to this entity next month.' Governance fires only at operations; the dooming event is time passing, which fires none. The temporal doc's own example shape compiles clean (probe-verified).
- **Severity/value:** Critical for the rule form (mass stranding at a date, refusing even the close-out path; falsifies the at-every-moment integrity claim while dormant); high for the guard form (silent Unmatched-forever traps).
- **Engine power needed:** Syntactic monotonicity taint over the closed temporal operator set (closing vs opening vs stable windows) crossed with write-site/fallback analysis — no solver, no intervals. Inspector-side: expiry metadata on verdicts plus a clock-simulation control (tooling).
- **Language change needed:** Optional unlock: a declared timeout/expiry-row form (kind sketch only — replaces host-side sweep jobs; net expressiveness GAIN). The warning needs no surface change.
- **Expressiveness cost:** None as warning; 'decaying rule requires a declared escape' is the right-sized posture — corpus has ~3 flag sites today (floor, not ceiling: authors worked around the missing surface with day-counters).

### [defect-class] Guard-locked strands and semantic dead-ends: per-state attainability/value envelopes vs exit-guard satisfiability

- **Why compile-time wins:** Directly redeems philosophy.md's 'no workflow trapped in a state it can never leave' — today only the structural subset is checked (guards deliberately overapproximated). Unmatched-forever has no signal: governance never refuses, and the inspector's 'blocked — AdjusterId is set' reads as 'not yet,' never 'never.' PRE0158 half-knows the fact and draws no consequence (probe-verified). The universal claim 'no reachable operation sequence ever establishes this fact' is exactly what sampling cannot state.
- **Severity/value:** Critical: the canonical stranded-process bug, discovered in production as aging stuck entities; ERP literature documents stuck workflows as a top operational failure of the systems Precept replaces.
- **Engine power needed:** The one genuinely NEW engine in the niche: per-state writable/attainable-fact sets composed with guard satisfiability, then (deeper tier) interval envelopes joined at states to fixpoint — converges without widening on finite declared bounds and ≤50 states per §0.4. Conservative outside the interval/presence fragment.
- **Language change needed:** None for the analysis; an optional 'perpetual'/hold intent modifier silences the warning for deliberate hold states.
- **Expressiveness cost:** Low: non-interval guards widen the envelope (fewer catches, no false rejections).

### [defect-class] Qualifier-source mutation obligation: writes to a field serving as a '{X}' qualifier base must prove dependent money/quantity values unset or at zero

- **Why compile-time wins:** Silently-wrong-money on the qualifier system's own source of truth: the write commits as a clean success, the magnitudes don't change (that IS the bug), and the QualifierCompatibility obligation currently reports 'Proved' across the hole. Live in a shipped sample (fee-schedule.precept) mitigated only by a prose comment deferring to a host-level approval flow — the exact scattered-rules pattern the product exists to eliminate.
- **Severity/value:** Critical: the flagship defense (currency safety) has a structural hole; failure surfaces as wrong financial figures or an unattributable backstop fault long after the causal write.
- **Engine power needed:** Static structural obligation reusing the presence/narrowing machinery behind PRE0116/PRE0141 — the compiler already knows the qualifier-dependency graph.
- **Language change needed:** Optional unlock: an explicit conversion-action construct for genuine convert-in-place flows (kind sketch only).
- **Expressiveness cost:** Moderate at the edge: convert-in-place becomes rejected-until-the-construct-lands rather than silently wrong — the rejection buys correctness; empty/zeroed switches need one guard.

### [defect-class] Decision-band completeness and overlap per (state, event): guard unions that leave uncovered input regions or ambiguous overlaps

- **Why compile-time wins:** A gap is found by the inspector only if the author happens to try a value inside it; the universal claim 'every representable input routes somewhere with a reason' needs interval-complement over the guard union. External demand is direct: DMN gap/overlap checking was built and validated against real credit-lending tables (Calvanese et al., solver-free interval geometry), and tiered approval bands are near-universal in procurement/finance with documented enforcement failure.
- **Severity/value:** Medium-to-high: a band gap is a stuck request with a reasonless Unmatched (the one refusal lane with no because); composes into permanent traps with the strand classes.
- **Engine power needed:** Interval complement of guard unions per row group — existing lattice; tier-1 (no unconditional/reject fallback) is purely syntactic.
- **Language change needed:** None for the lint; a total-routing rule would be a posture decision, not new surface.
- **Expressiveness cost:** None as advisory; the suggested fix (one reject fallback row) forces an authored refusal reason where today there is none.

### [ux-unlock] Static contract projection: offline per-state form contracts (types, effective bounds, requiredness, editability, choices, because catalog), AOT state×event availability maps, generated typed host contracts

- **Why compile-time wins:** The round-trip paradigm is per-scenario, instance-bound, online-only, and quadratic — the prototype carries the scar tissue (one inspect per event per refresh, 30/140ms debounces, sequence-token races, probe-arg synthesis), and the manifest's own open questions request exactly a static contract ('requiredness as a surface semantic rather than an inferred styling choice'). A contract consumed by another compiler or an offline client is something a live evaluator structurally cannot be.
- **Severity/value:** Rated transformative in the UX evidence (rjsf/GraphQL-introspection/OpenAPI-generator precedent ecosystem); converts constraint-discovery-by-refusal into constraints-as-affordances for every end user on every keystroke.
- **Engine power needed:** HONEST CAVEAT: mostly projection of descriptor tiers and interval machinery the Option-1 fault floor already builds — emitters, not new proof power. Guarded/relational residue must be honestly exported as 'evaluator-required.' This unlock alone supports the middle reading, not all-in.
- **Language change needed:** None.
- **Expressiveness cost:** None — read-only export; honesty discipline required (never render approximation as exactness, Principle 8).

### [ux-unlock] Counterfactual refusal guidance and instance-free authoring verdicts: 'raise Score to at least 680' computed from the effective interval/relational intersection; contradictions/vacuity/dead-guards/traps surfaced in domain vocabulary while typing, no instance to construct and steer

- **Why compile-time wins:** The inspector answers pass/fail for the values typed; finding the boundary is manual binary search, and the effective bound is the intersection across rules + ensures + guards that only the proof representation knows. Landscape verdicts are universal claims (no data can satisfy this guard) that sampling cannot make. Wachter et al. counterfactuals are the established gold standard for decision explanation — Precept computes them exactly where ML approximates; Dafny-IDE precedent shows as-you-type proof feedback is a valued paradigm.
- **Severity/value:** Significant: this is where Option 2 specifically earns UX differentiation beyond floor projections — the proof-DEPENDENT unlocks.
- **Engine power needed:** A boundary-query surface over the interval/relational representation (spec §0.6 #13 already mandates structured proof attribution); the landscape verdicts ARE the §0.6 items 7–10/12 obligations surfaced live.
- **Language change needed:** None.
- **Expressiveness cost:** None — inherits the soundness prerequisite: a false landscape verdict (the PRE0155 behavior verified live) is worse than none.


## Not worth it (governance + inspector suffices, or out of scope)

### Wrong-but-in-band formula/operator/constant errors (OutstandingBalance <- Labor + Applied instead of minus; threshold typed 608 for 680)

Undecidable for ANY compile-time system — intent is not in the artifact. The live inspector showing the computed number against the author's mental arithmetic is the only catch that exists in any tool; this is the single most business-severe value class and it is direct evidence FOR keeping the inspector central. Compile-time can only shrink the escape space via dimension checks (shipped) and bounds discipline (shipped where declared).

### First-fire universal refusals with self-diagnosing because-text (never-committable mutation rows under equality rules; phantom omit×rule face; entry-ensure contradictions on well-trodden paths)

Governance refuses loudly, deterministically, at the first attempt, with the mandatory rationale naming the exact violated relationship — 'effectively a compile diagnostic delivered slightly late.' In the designed per-keystroke authoring loop these surface during authoring. Compile-time versions are worth having eventually as attribution polish (the refusal blames data for a definition bug), but they are not niche-defining. Caveat retained: library-book-checkout shipping the exit-hook contradiction shows the escape rate is nonzero, which is why the contradiction FAMILY stays in the niche — only the well-exercised-path subset is governance-sufficient.

### Semantic mischoice family: accessor mischoice (.first vs .min vs .peek), set silent-deduplication vs count gates, duration-vs-period, verdict-tag misclassification, quantifier any/each at full strength

Intent mismatch between two well-defined semantics — statically undecidable, and the inspector's sweet spot: a single distinguishing two-element or boundary scenario exposes each immediately. Right-sized as hover/paraphrase/witness authoring surfaces (the quantifier polarity lint is worth shipping as a heuristic), not proof work.

### Doomed-trajectory enforcement at runtime (refuse the dooming input at commit) and blanket prove-or-reject mandates (mandatory arg bounds on all args, mandatory fallbacks, conservative doom-refusal)

The corpus idiom (unconditional Decline/Cancel escapes, 258 reject rows) makes completability pass nearly everywhere already; conservative doom-refusal risks refusing savable entities — the evidence's own warning. And the cost simulation shows the same capabilities flip from cheap to punitive under blanket mandates: the warning/obligation-driven form captures the value. The backward-fixpoint warning tier can follow the strand-envelope work later; the runtime refusal form should not lead.

### Definition-evolution safety (fleet bricks from tightened rules, removed states, default skew, routing drift — both versions compiling clean)

Governance does NOT suffice here — this is the most severe uncovered family in the entire evidence base. It is excluded from THIS niche because it is structurally a two-definition deploy-gate lane plus envelope-fingerprint substrate, orthogonal to single-definition compile strength under either option. It deserves its own decision; folding it into Option 2 would blur the teachable line and overstate what 'compiles clean' can ever mean about persisted fleets.

### Host-integration residue (restore-as-backdoor, wrong-definition restore, lost-update concurrency, outcome mishandling, restored-collection structural invariants)

Evidence-neutral between the options: no definition-level compile checking touches host C#. The fixes are engine-surface hardening (envelope fingerprint/signing, Version etag, inspection-result wrapper, restore-time structural normalization, Roslyn analyzer) — Option-1-compatible floor work that should proceed regardless.


## Predictability assessment (the consistency criterion)

Both red-team predictability attacks are real and one was verified live this session: (1) An ordinary edit CAN silently move a rule across the line — the same unsatisfiable relation written as modifier bounds (Probe33), guarded field-RHS rules, or literal-RHS rules gets three different guarantee levels; parameterizing a constant or adding a third field to a relation silently exits the proven fragment. (2) Engine growth under a prove-or-reject posture WOULD retroactively change which definitions compile (depth bumps, fragment extensions), reproducing Dafny-style brittleness without a solver. (3) Verified live: PRE0155 currently fires a false 'no valid configuration can satisfy both' on provably-disjoint guards (premium-cap vs silver-floor — an idiomatic, satisfiable tiered policy), identical to the genuine same-guard contradiction, with a raw TypedBinaryOp dump as the message — the shipped increment over-claims today, so promote-to-error is demonstrably unsafe as-is. THE RESOLUTION that makes the partial shape predictable: invert the guarantee direction. The fault floor stays prove-or-reject (total, stable). Everything else in the niche ships under a FLAG-SOUNDNESS contract: a flag is always a true universal statement about the definition; silence beyond the fault floor promises nothing. Under that contract, an edit crossing the fragment boundary can only lose a warning (never gain a false rejection); engine growth only adds flags without changing the meaning of existing ones; and the green proof ledger never claims more than the floor — which also addresses the three verified false-'Proved' sites (Probe34 mincount, qualifier-source, presence-wrapping-contradiction). Error promotion is then a per-diagnostic earned status (soundness verified, guard-scope-sensitive), not a posture. The teachable line above is exactly the sentence this contract makes true; the all-in prove-or-reject identity claim admits no such sentence today and is rejected as inconsistent.

## Today vs growth

AT TODAY'S EXPRESSIVENESS: the niche's corpus catch-rate is honestly near zero against the 77 idiomatic samples (zero real quantifier usage, 3 now()-in-rule/guard sites, 3/296 all-guarded-exit states, safe idioms dominant) — but the corpus-bias rule applies with force: the samples were authored by people who knew the safe shapes, three inspector-blind defects still shipped in hand-polished samples (fee-schedule qualifier hazard, library-book-checkout hook contradiction, loan-application reject divergence), and demand evidence independently lands on the same analyses (DMN gap/overlap validated on real credit-lending tables; stuck workflows a documented top ERP failure; rule contradiction a named production-bug class). Today the case rests on floors-plus-demand, not measured corpus incidence — that is the honest epistemic state. AT PLAUSIBLE GROWTH: the case compounds rather than erodes. Quantifiers seeing real use activates the entire quantified family (mischoice, vacuity, dead guards) where the inspector is weakest (small collections make all quantifiers coincide); a deadline/expiry surface and now()-guards in real SLA domains (CMS 72h/7d is regulatory) activate the clock classes; collection aggregation (the most-demanded expressiveness gap, mattering under either option) creates new universal cap-erosion claims interval reasoning is built for; type-level default bands dissolve most of the bounds-invention ceremony. Conversely, growth raises the predictability stakes: every new construct widens the fragment boundary, which is why the flag-soundness contract (not fragment enumeration) must be the stable public promise. The evolution lane also grows more urgent with any real deployment — schedule its decision before first external users, independent of this one.

## Right-sized scope (the recommended shape)

A three-layer shape, deliberately short of all-in: LAYER 1 — FAULT FLOOR, COMPLETED (prove-or-reject, total): close every probe-verified breach (overflow obligations, choice-default membership, mincount-at-birth, because/reject interpolation binding, omit×global-rule join, binder shadowing/unused-binder, hook-guard PRE0082 coverage, qualifier-source obligation) and fix the three false-'Proved' ledger sites. This is owed under either option and is most of the near-term work. LAYER 2 — PROVEN-VIOLATIONS UNIVERSAL LAYER (conservative, flag-sound, warning-default with earned per-diagnostic error promotion): the niche list above — contradiction/vacuity/dead-guard family made guard-scope-sensitive (fixing the verified PRE0155 false positive and the raw-AST messages first), shadowing tiers, band-coverage, clock-decay taint, strand/envelope analysis, quantified extensions. This finishes spec §0.6's own specification-only commitments; it is a real identity claim ('the compiler proves your definition cannot fight itself') without the unteachable prove-or-reject boundary. LAYER 3 — STATIC CONTRACT PROJECTION: form contracts, availability maps, host codegen, counterfactual boundaries, landscape verdicts, liveness certificate, inspector clock-simulation control — static-first consumption with the live inspector retained as the concrete-value escape hatch (it remains the ONLY catch for the undecidable-intent residue, including the most business-severe class). EXPLICITLY DEFERRED to separate decisions: the definition-diff/evolution deploy lane (severe, uncovered, orthogonal — needs envelope fingerprinting substrate); doomed-trajectory runtime refusal; any blanket-mandate postures; the sketched language unlocks (expiry rows, conversion action, sealed-after family, structured reject) which route to /design individually.

No capability in the recommended scope carries unavoidable severe expressiveness loss — the cost simulation's central finding held up under adversarial reading. The verified all-in rewrite of the flagship sample ended 28 lines SHORTER (109→81), compiled clean with every obligation Proved, trading 8 invented bounds + 1 presence guard + 1 opt-in door ensure against 5 hazardous sentinel defaults deleted. Mitigations: obligation-driven posture only (bounds demanded where arithmetic/sinks require — ~30-50 declarations corpus-wide vs ~800 under blanket mandate), and type-level default representable bands as catalog metadata (small, non-grammar change). The friction literature's adoption failures (Dafny uncanny valley, proof brittleness on rename, 16 person-months) attach to SMT-backed verification the scope forswears — but note honestly that the red-team demonstrated a depth-one version of the same valley in the solver-free fragment (silent fragment exits, the live false positive), which the flag-soundness contract exists to cap, and that no external comparator exists for solver-free DSL-scale checking: that gap is unmeasured, not cleared. Posture discipline is load-bearing: several capabilities are cheap ONLY in warning/obligation form; the same checks under blanket prove-or-reject flip punitive.
