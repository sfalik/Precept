## Finding 1 — [Q2, HIGHEST THREAT] P4's "UNWRITABLE rows: none" is false: a true nonlinear invariant on a derived value is unwritable-as-checked, and P4's escape E4 is circular for derived writes.

**The capability removed:** declaring a *provable-on-paper, always-true* invariant on a derived value and having the compiler check it. Exemplar (P2 §6, verified):

```
field GrossIncome as money in 'USD' positive
field EffectiveRate as decimal max 0.37   # true: effective rate never exceeds top marginal rate
-> set EffectiveRate = TaxDue / GrossIncome   # TaxDue piecewise-linear, constants only
```

`EffectiveRate = 0.37 − 12019.5/GrossIncome < 0.37` for all `GrossIncome > 0` — mathematically always in-band, **never reachable**. Under pure prove-or-reject this field **rejects** (division cancellation of `GrossIncome` through a piecewise numerator is outside "standard interval arithmetic, bounded relational closure" — `precept-language-spec.md:174`, and the symbolic simplification that would prove it is the opaque-witness class excluded at `:225`).

**Why P4's forceability theorem has a hole here.** P4 Table row 3/4 escape **E4** = "restate the invariant as a governed `rule`, ingress-enforced ⇒ sound premise." That is **circular for a derived field**: `EffectiveRate` is never an ingress value — it is computed. Per `:266`/`:268` a derived write must *prove* it satisfies every rule; `rule EffectiveRate <= 0.37` therefore converts the field-bound obligation into an identical *rule* obligation on the same unprovable write → same rejection. E4 discharges only when the rule constrains a *different, ingress* field (P4's own rows 3–4 use `Withdrawals`, `Refund` — inputs, not the derived target). For an invariant *on the derived value itself*, **no source bound terminates the obligation** (P2 §6 "bound the source does not terminate here" — verified: chasing reaches `GrossIncome`, already `positive`, and no bound on it discharges the ratio). E1 self-guard does not rescue the *invariant* either — it produces a runtime gate, not a proven property (see Finding 2).

**Cross-confirmation from prior art (P5, decisive).** Every comparator surveyed — SPARK/GNATprove, Frama-C, Dafny, F*, Liquid Haskell — keeps a **Tier-2 "supply a decidable checked fact" mechanism** (ghost lemmas, `calc`, ACSL lemmas, refinement reflection) *specifically* so a nonlinear invariant the solver can't auto-prove can still be **stated and discharged by a hand proof**, or a Tier-3 `assume`/`admit` trust escape. Precept's `rule` is its Tier-2 — but only for the **linear/octagon fragment** (`:256` "single-pass and depth-bounded, no transitive chasing of a third field"). **Pure prove-or-reject with no lemma and no assume-escape is the only posture in the surveyed field with *neither* discharge path for nonlinear facts.** P5: "No comparator combines solver-free + gating + no-trust-escape." That is precisely this posture. The capability every comparator preserves — *write down a true thing the checker can't derive* — is the one pure prove-or-reject removes.

**Threat magnitude:** This is stronger than any Q1 finding because Q1 always has the (ugly) dead-guard workaround, whereas here there is **no workaround at all**: the invariant genuinely cannot be expressed-and-checked. It directly contradicts the §0.8 audience commitment P2 cites ("the domain expert declares what they know to be true") — "effective rate never exceeds top marginal" is exactly such a truth, and the posture makes it unwritable.

**The ceiling-conditionality (the honest crux the owner must decide).** The tax case is unprovable under the **literal** §0.4/§0.7 ceiling ("standard interval arithmetic, bounded relational closure" — no symbolic algebra, no polynomial division: interval arithmetic does not simplify `GrossIncome/GrossIncome`). The genuinely irreducible survivor is therefore: **a closed-form algebraic identity (not a stateable business correlation) that is always-in-band, where GrossIncome-style operands are already maximally bounded and the only discharge is symbolic manipulation the ceiling excludes.** The tax effective-rate is its cleanest exemplar and it survives under the literal ceiling.

**Verdict:** Q1 FORCES-WORSE **survives, narrowly, and ceiling-conditionally.** It is weaker than Finding 1 because (b) is an expressible (if ugly) workaround.
