- 2026-07-06 — **Band-model ruling operation (Phase 3 — THE RULING).** Ruled decisively: **Hybrid** governs Precept. Deliverable: `docs/Working/proof-engine-boundary-ruling-2026-07-06.md` (status: Draft, pending Shane). Verified every linchpin first-hand at HEAD `e09f1af4`.
  - **The ruling (one line):** the compiler is TOTAL over the definition-internal surface (every value produced by evaluating a Precept expression is prove-or-reject for any fault/bound obligation — no deferral); runtime governance is real but confined to raw host-supplied values at their ingress slot, checked against that slot's own contract. This is spec §0.7 (`:266`/`:268`) as already written, made precise and defended against the D2 drift.
  - **The anti-slippery-slope device — the ingress-origin predicate:** a value is runtime-governed iff ALL of (1) host-origin (construction input / event arg / direct edit — not an expression result), (2) ingress edge (before any expression derives from it), (3) same-slot contract (the slot's own declared contract, NOT a stricter downstream target's band), (4) no expression node between raw input and check. Else → definition-internal → prove-or-reject. **Decidable from the typed IR, no solver.** Key property: "not statically decidable" is NEVER a routing criterion — that's what stops the slide (Model A routes by decidability = slippery; Hybrid routes by origin = stable).

Runtime-absence merely PRICES A (must build a whole band-governance surface), it doesn't defeat A. A is wrong on identity.

Key insight: a nonlinear `rule A*B == C` is a GOVERNANCE constraint (§0.7:268, always enforced at runtime as a rule), NOT a deferred fault. Pure-B conflates the two mechanisms. Hybrid governs the rule (expressible) + prove-or-rejects its arithmetic for overflow. Zero expressiveness loss where pure-B has total loss — the decisive win.
